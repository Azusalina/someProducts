DEFINE THE MANDATE

Strategy settings.

Set the USDC budget, trading rules, and execution limits.

PAUSE TO EDIT
01 / CAPITAL

Choose the allocation

Fund a dedicated Base wallet with USDC and native ETH for gas. This budget defines the strategy’s initial USDC allocation.

Set both to 100 to permit use of the full allocation. A small execution reserve still applies. Spot swaps only. Native ETH for gas stays outside this budget.
02 / ENTRY & EXIT

Follow an hourly trend

Buy when the fast average is above the slow average and the current price is above the slow average. Exit on a trend reversal, stop loss, or take profit.

Crypto markets run 24/7. Exits run on scan intervals with minimum-output protection. They can fail during RPC outages or fast moves. Keep the engine running.
03 / OPERATING LIMITS

Know when to stop

Loss limits pause automation and leave holdings open. You can review and close holdings separately.

At most one entry per symbol per UTC date. Exits can exceed the daily order cap.

Pause automation before saving changes.

04 / ON-CHAIN EXECUTION

Bound every swap

Only the allowlisted Base tokens and fixed Uniswap router can be used. The recipient is always your trading wallet. Gas is paid in native ETH, outside the USDC equity chart.

100 bps = 1%. Gas estimates include a reserve for Base L1 fees; actual fees can vary. Native gas is reported separately.
