# ICT Unit C study pages

## What is it?

A set of plain-words study pages for ICT Unit C (Computer and its Applications), rebuilt from `../notes/c.pdf`. There is one page per chapter (Ch16 to Ch20) plus an overview page. Each page opens with a short animation of the chapter's core idea, explains the ideas in simple language, keeps the exam tables, adds interactive demos and quizzes, and ends with self-check questions. The look is Apple-inspired: large type, glass navigation, soft cards, light and dark themes.

## How to use

- **Prerequisites:** any modern web browser (Chrome, Firefox, Edge, Safari). No internet connection, server, or install is needed.
- **Open:** double-click `index.html` in this folder, or run `xdg-open index.html`. Use the top bar to switch chapters.
- **Study:** read the explanation, try the interactive box under it (buttons, sliders and text fields), then answer "Check yourself" by opening each question only after you have answered it yourself.
- **Configuration:** none. The pages follow your system light or dark setting and reduce animation if your system asks for reduced motion.
- **Removal:** delete this `learn` folder. Nothing is installed elsewhere.
- More detail (file list, sources, corrections found in the notes, maintenance) is in [description.md](description.md).
