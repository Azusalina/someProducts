Introduction to HTML

A web page is plain text with tags. Learn the tags and how HTTP delivers them.

What HTML is

HTML (HyperText Markup Language) is a markup language: you write ordinary text and add tags that describe each part (this is a heading, this is bold, this is a link).

  • An HTML document is plain text (ASCII characters only), so it can be written in any text editor.
  • A tag is enclosed in angle brackets < >. Tags are not case-sensitive: <B> and <b> are the same.
  • HTML is not a programming language. It describes appearance and content. It has no IF or loops, so a page written in pure HTML cannot make decisions.
  • It does not depend on the operating system, so the same page works on any computer with a browser (cross-platform, portable).
  • Hypertext is text that can link to another document.

A web page is a document written in hypertext format. A web browser (the HTTP client) reads the tags and displays the page.

HTTP: how the page reaches you

HTTP (HyperText Transfer Protocol) is the application protocol that carries hypertext documents from a web server to a browser. The browser sends a request; the server sends back a response.

Request methodWhat it asks for
GETGive me this resource from the web server.
POSTHere is data (for example a form) for you to process.
HEADSend me only the header of the response, not the page itself.

    Tag reference
    

    Page and body
    

    CodeEffect
    

    <BODY text="#00FF00">Sets the text colour of the whole page
    

    <BODY background="xxx.jpg">Uses the picture as the page background. If the picture is smaller than the screen it is repeated (tiled) to fill it.
    

    <BODY bgcolor="orange">Sets the background colour
    

    <FONT size=7>Sets the font size
    

    <FONT face="Times New Roman">Sets the font face
    

    <EMBED src="xxx1.mp3"></EMBED>Background music, played automatically
    

    

    Layout
    

    TagEffect
    

    <H1>...</H1> to <H6>Headings. H1 is the biggest, H6 the smallest.
    

    <BR>Line break
    

    <CENTER>...</CENTER>Centre alignment
    

    <FRAME>Names which page loads first in a frame (a frame is one pane of a window split into several)
    

    

    Text format
    

    TagEffectTagEffect
    

    <B>Bold<SUP>Superscript, for example x2
    

    <I>Italic<SUB>Subscript, for example H2O
    

    <U>Underline<FONT>Font face, size, colour
    

    

    Images and links
    

    CodeEffect
    

    <IMG src="xxx.jpg">Shows an image. src is the image file.
    

    <A href="page.html">text</A>A link. href is the hypertext reference (where it goes).
    

    <A name="example1">Names a spot on the page (an anchor)
    

    <A href="#example1">Jumps to the anchor named example1 on the same page
    

    

    Frame attributes
    

    AttributeMeaning
    

    name="xxx"Name of the frame
    

    src="xxx"The web page to load into the frame
    

    scrolling="auto | yes | no"Whether scroll bars are allowed
    

    frameborder="1 | 0"Border on (1) or off (0)
    

    marginwidth, marginheightWidth and height of the frame margin
    

    target="_self | _parent | _top | _blank"Where a clicked link opens: in the same frame, the parent frame, the whole window, or a new window

    Colour in HTML
    

    There are two ways to write a colour: a colour name (orange, white, blue) or a six-digit hexadecimal code #RRGGBB: two digits each for Red, Green, Blue, from 00 (none) to FF (255, full).
    

    
  
    Mix a colour

    Frames
    

    A frame splits the browser window into panes, and each pane shows a different page. A common layout is a narrow menu on the left that stays still and a large pane on the right where the clicked page opens. The target attribute of a link decides which pane the page opens in.
    

    
  
    Where does the link open?
    
  
    Click a link in the menu pane and watch where the page shows up. Switch the link's target.

    Check yourself
    

    Why is HTML called a markup language and not a programming language?
    It only marks up (describes) text with tags. It has no decisions or loops (no IF), so it cannot run logic.
    

    What kind of file is an HTML document, and what must the tags look like?
    A plain text (ASCII) file. Tags are enclosed in angle brackets and are not case-sensitive.
    

    What is the difference between HTTP GET and POST?
    GET requests a resource from the server. POST sends data (such as a form) to the server to be processed.
    

    Write the tag to set the page background to orange.
    <BODY bgcolor="orange">
    

    What colour is #00FF00? And #FFFFFF?
    #00FF00 is pure green (red 0, green 255, blue 0). #FFFFFF is white (all three at full).
    

    Write a link that jumps to an anchor named "top" on the same page.
    <A href="#top">Go to top</A>, with an anchor <A name="top"> somewhere on the page.
    

    What does target="_blank" do?
    Opens the clicked link in a new window.
