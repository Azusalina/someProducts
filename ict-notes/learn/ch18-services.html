Chapter 18

Services and applications

Find information, judge it, and use the services built on the Internet.

Finding information

A search engine is a set of programs that finds web pages for you. It works in three moves:

  1. Crawl. A program called a spider (or bot) follows links across the World Wide Web and visits pages.
  2. Index. It stores the words of every page it found.
  3. Match. When you type keywords, it matches them against the stored pages and returns the pages that fit.

Is the information any good?

Search results can be wrong, old or biased. The notes give six checks. Ask each question about any page you plan to use.

Internet services

Web browsing means navigating, reading and interacting with sites on the World Wide Web. The web uses HTTP to move pages between a web server and your browser.

WWW is not the Internet

The Internet (a very large WAN) is the network. The World Wide Web is one service that runs on it. E-mail and FTP are other services on the same network.

    Check yourself

    What does the spider of a search engine do?

    It follows links to find web pages and stores their content so the engine can match your keywords later.

    Write a search that finds pages about "python" but not "snake".

    python NOT snake

    List the six checks for judging information.

    Completeness, accuracy, authority, objectivity, timeliness, legality.

    Why are vector graphics good for logos that must be printed at many sizes?

    They are stored as shapes and formulas, so they can be scaled up without becoming blocky.

    Why is SSH preferred over Telnet?

    SSH encrypts the data, so a password cannot be read by someone watching the network.

    What is the advantage of streaming?

    Playback starts almost at once; you do not wait for the full file to download.

    Which protocols are used for e-mail?

    SMTP to send; POP or IMAP to receive.

    What do EFT and EDI do for e-commerce?

    EFT moves money between bank accounts. EDI exchanges business documents in a standard format. Together they raise accuracy and cut administration cost.
