# sheetVis

## What is it?

本机运行的钢琴乐谱瀑布播放器。导入清晰 PDF 后，本地识别并播放；也可直接导入 MusicXML 或 MIDI。五线谱、音符瀑布与钢琴声音共用播放时间线，支持调速、暂停、快进和回退。

识别结果可能包含错音或节奏偏差。详细功能、开源来源、限制与验证记录见 [description.md](description.md)。

## How to use

适用环境：Linux x86_64，现代 Chromium／Firefox 浏览器，Node.js 20.19+（或 22.12+）、npm、Python 3.12+，以及 `ar`。Audiveris 自带 Java 运行时，无需另外安装 Java。

可选的 Poppler 工具 `pdffonts`、`pdftotext` 用于读取数字 PDF 内嵌拍号，当前 Linux 电脑已具备。缺少时仍可使用 Audiveris 图像识别。

首次准备需要联网下载依赖、本地识别引擎和钢琴采样；准备完成后运行无需联网：

```bash
cd /home/a/Documents/someProducts/Visualize-sheet
npm ci
npm run setup
npm run build
./launch.sh
```

`launch.sh` 会打开浏览器。也可运行 `npm start`，然后访问 <http://127.0.0.1:4280>。关闭启动终端或按 `Ctrl+C` 停止服务。

在“乐谱缓存”中设为默认的已完成记录会优先打开，直接复用其结果；未选择缓存时，默认读入 `config.json` 中指定的 `/home/a/Documents/materials/PianoSheets/chopin_ballade1.pdf`。已完成的相同 PDF 复用本地识别记录，刷新不会重复识别。浏览器首次打开需要点击“播放”或按空格启用音频；之后导入文件可自动播放。默认文件缺失会显示错误；工具栏仍可导入其他文件或选择示例。

- 默认深色界面，工具栏收起。点击右侧“工具”或按 `Tab` 呼出右侧垂直工具栏，`Esc` 或关闭按钮收起。
- 从工具栏“导入”或将文件拖入瀑布区。支持 `.pdf`、`.musicxml`、`.xml`、`.mxl`、`.mid`、`.midi`，文件最大 40 MB。
- 识别进度条右侧和“乐谱缓存”中都有“中断识别”。取消排队不会影响其他任务；中断运行任务后保留上传文件、日志及已保存检查点，未保存的当前阶段可能重算。
- PDF 先筛选含五线谱的页面，作曲家介绍、作品说明等无谱页不参与音符识别。页面显示筛选／识别百分比进度，完成后默认自动播放；取消“自动播放”可改为手动开始。多乐章结果可以切换乐章。
- 工具栏“乐谱缓存”可查看本地 PDF 识别记录、状态、时间及大小；“打开”直接复用该记录，“删除”移除缓存中的上传副本、识别工程、结果与日志，不改动电脑上原来的 PDF。排队／识别中的任务可先点“中断识别”，中断完成后允许删除；也可点“继续识别”重新处理并复用有效检查点。正在播放的内容可继续使用，删除后下次导入需重新识别。已完成缓存可“设为默认”，下次启动直接打开；删除默认缓存会恢复原默认文件设置。
- 缓存中的“八度训练包”下载独立 OMR 工程、候选页面、待人工标注的清单与训练说明；可先在 Audiveris 校正，再采集样本并训练。现有错误识别不会自动成为训练真值；当前没有执行新模型训练。“反馈”会列出八度线范围、谱表位置及原 PDF 文本标记的核查结果。
- 文件读入后显示文件名、大小、页数与状态。点击“反馈”展开音符／分手统计、引擎节奏异常、起奏位置缺失和播放限制。检查结果不提供未经原谱核对的准确率。
- 工具栏“瀑布配色”可调整左右手、触键和背景颜色，立即生效并保存到当前浏览器。`config.json` 的 `colors` 是默认配色；“恢复配置配色”清除浏览器覆盖。修改配置文件后刷新页面即可读取。
- 工具栏“Zen”或非输入区域按 `Z` 进入只显示瀑布与键盘的模式，`Esc` 退出；空格、方向键、点按琴键与高度拖动继续可用。
- 上下拖动钢琴上边界可调整琴键高度，设置保存在浏览器中。点按白键或黑键发出对应音高，不改变当前播放位置。
- 点击原 PDF 中已定位的符头，或重建五线谱中的可播放符头，会跳转到该音符并继续播放；反复段选择离当前进度最近的一次。空白处或缺少可靠定位的音符不触发跳转。
- 鼠标位于右侧瀑布／键盘时，滚轮向下前进、向上回退；连续滚动期间暂缓播放，停下后恢复原播放状态。原本暂停则继续暂停。`Ctrl`＋滚轮保留浏览器缩放。
- 左侧显示上传的原 PDF，右侧显示瀑布与键盘。播放时高亮当前音符及和弦，并自动切换页面；“跟随”可关闭自动换页，页码和箭头可手动浏览。未找到可靠原谱坐标的音符不显示猜测光标。定位覆盖率不等于识别准确率。
- 顶部识别进度条下方、琴谱／键盘上方常显“播放／暂停”和可拖拽的播放进度条。拖动期间暂停，松开后恢复之前的播放状态；暂停时也可拖动定位。“工具”中的 `−5s`、`+5s` 和小节按钮也控制位置。空格切换播放／暂停，播放按钮或进度条聚焦时同样有效；文字、数值和选择输入保留自身键盘操作。左右方向键跳转，`Home` 回到开头。
- 识别结果支持八度线、行内高／低音谱号变化、延音线、连奏线和三／五连音。琶音波浪标记按上行／下行分散起奏，保留和弦原结束位置；普通分解和弦按写出的音符播放。延音线合并时值，连奏线保留各音并衔接；“反馈”显示识别标记数量及缺失配对。八度线终点等漏识别仍需核对原 PDF。
- 支持倚音、颤音、上下波音、回音及延迟回音。倚音从相邻主音借时；声音、瀑布与原谱高亮使用同一时间线。“反馈”显示谱面记号与生成击键数量，并标明常见奏法的近似处理；复杂或无法可靠定时的记号保留谱面并提示检查。
- 速度范围为 0.25–2 倍，保持音高。BPM 可输入 20–300，用于校正未识别的参考速度；倍速基于该参考速度。可独立关闭左右手声音、调整音量和瀑布预览时长。
- PDF 默认显示原文件；从工具栏“五线谱”按需打开重建预览，避免载入长谱时等待整首重新排版。重建五线谱模式也按当前音符移动光标并自动滚动，拖动进度条和回退会同步定位。可下载识别后的 MusicXML，在其他乐谱软件中修正。MIDI 不提供五线谱预览。
- 默认服务仅监听本机。用 `python server.py --port 4282` 更改端口；设置 `SHEETVIS_AUDIVERIS=/绝对路径/Audiveris` 可使用已有引擎。`config.json` 的 `default_score` 可设为空以默认打开示例，也可用 `SHEETVIS_DEFAULT_SCORE=/路径/乐谱.pdf` 覆盖。`recognition_timeout_seconds` 设置识别预算（默认 3600 秒，范围 30–7200）；失败任务保存 `.omr` 阶段，重新导入相同 PDF 可继续。

工具栏“识别资源”可设置 CPU 核心预算与 Java 内存上限并保存到配置文件。正在运行的任务保持现有设置，下一次新识别使用新值。识别条会显示最近处理的页码、阶段，以及日志确实提供的系统／小节 ID；小节 ID 可能是引擎页内编号，未提供时不推测。

识别默认使用本机多核并行。`config.json` 中 `recognition_threads: 0` 自动选择最多 8 个核心；设为 `1` 使用单核，或设为 `2–64` 指定 CPU 核心预算（不超过可用核心数）。`recognition_memory_mb: 4096` 设置 Java 堆上限；自动模式在低内存时会降低资源用量。代码更新后重启服务一次，之后配置改动在下次新识别任务生效。已有完成结果继续使用缓存。

识别记录与原 PDF 保存在 `.data/`，依赖引擎保存在 `.runtime/`，钢琴采样保存在 `public/samples/`。停止服务后可删除 `.data/` 清除识别记录。无需系统安装；停止服务并删除产品文件夹即可移除工具。
