## What is it?

graphVis 是极简的离线函数绘图与微积分可视化工具。输入表达式即可绘图，支持参数滑块、导数曲线、可拖动切线、定积分阴影和累积积分曲线。

设计参考 Desmos / GeoGebra 的公开交互，MathLive 编辑器与字体随项目保存，运行时无需网络。架构、来源、算法、限制与验证记录见 [description.md](description.md)。

## How to use

使用支持 Canvas、ResizeObserver、Web Components 和 FontFace 的现代浏览器，直接打开本文件夹中的 [index.html](index.html)。无需安装、编译或联网；保留同目录的 CSS、JS 和 vendor 文件夹。

首次打开为空白。点击左上角唯一的 `⋮` 按钮，呼出表达式列和工具栏；再点收起。表达式列只放公式和计算结果，其他控件均在独立工具区。

支持直接键入或粘贴数学 LaTeX，编辑和数学结果都显示为排版后的公式。例如：

```text
f(x)=\sin x
f'(x)
\int_0^x f(t)\,dt
```

- `Enter` 新建下一行；方向键在行首、行尾切换；空行按 Backspace 删除。支持多行粘贴和数学编辑器的括号、分数、上下标编辑。
- `a=2` 生成参数滑块，在独立工具区的“参数”中调整。`sinx`、`sin x` 等价于 `sin(x)`；`sin^n(x)` 表示 `(sin(x))^n`，n 可由参数定义。
- 工具栏的 f(x) 按钮展开独立数学工具区，在“微积分”选择函数，勾选切线或定积分；修改 x₀、a、b，或直接拖动图上的切点和边界。积分着色蓝色为正、红色为负，交换上下限时符号反转。
- `int(f(x),0,2)` 求定积分数值；`int(f(x),0,x)` 绘制累积积分；`int f(x) dx` 选择 F(0)=0 的原函数。使用其他起点时显式填写下限。
- 拖动图区平移，滚轮或 `＋ / −` 缩放；“⌂”恢复视图，“适应”按当前横轴范围调整函数视图。x、y 轴保持相同单位比例。
- “视图”设置网格、弧度/度、中心和横轴宽度。小键盘按钮单独位于屏幕底部，按需显示或隐藏小键盘。Ctrl+/ 呼出工具，Esc 收起。
- 选中公式后，用工具栏的可见性、颜色、删除按钮操作当前表达式。“保存 / 打开”导出、导入 JSON 项目；“PNG”导出图区。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。

内容会尝试保存在当前浏览器的本地存储中。直接打开文件时，存储行为取决于浏览器；重要项目请下载 JSON。“打开”会替换当前项目，可撤销。浏览器若限制本地文件，可在该文件夹运行 `python3 -m http.server 4178 --bind 127.0.0.1`，再打开 `http://127.0.0.1:4178/`；用 Ctrl+C 关闭服务。

没有系统安装或后台服务。移除时删除本文件夹；浏览器中的记录可在网站存储设置中清除。
