# JUPAS Analysis · HKU

中文交互分析模型，范围按用户确认：**HKU、2027–28 本科入学、香港薪酬为主并补充海外对照**。

```bash
cd /home/a/Documents/someProducts/d-jupasanalysis
npm run dev
```

打开 http://127.0.0.1:8791 。无 npm 依赖；只监听 loopback。也可直接打开 `index.html` 查看页面，但完整交互需 HTTP 服务加载 ES module。`PORT=8792 npm run dev` 可更换端口。

## 功能

- 11 个方向：CS、AI & Data Science、Applied AI、FinTech、Actuarial Science、BStat 的 DA / RM / ST、跨院 BA & BEng、IBGM、QFin。
- Applied AI 列出五个 concentration；2027–28 的入学入口为 6999，2026–27 参考入口为 6224。
- 6200 Delta+ 独立说明，避免把同一 BEng 学位重复计为新专业。
- 可选择任意组合的横向路径图，支持滚动、鼠标拖动、缩放、节点详情；手机保留完整路径。
- 15 个香港／海外授课硕士例子、研究硕博分支、补强课程与第二专业建议。
- 香港薪酬区间图、美国职业中位数对照、历史毕业生调查；保留原年份、币种及经验口径。
- 升学机会成本与累计折现现金流，资助月数单独设置；HKPFS 模板不把三年资助延长至四年。
- 官方链接、核查日期、事实与推断说明、研究数据 JSON 导出；地图选择与主题存储在本机浏览器。

## 数据与方法

核查日期：2026-10-03。来源登记在 `data.js`，界面可直接访问原文。当前本科规例目录为 2026–27，2027–28 入口调整另据 CDS 官网公告。课程定位可延续参考，但没有冒充 2027–28 最终课程学分表。

本科范围指所列 CDS 本科学位／专业核心与跨院双学位，再加用户指定的商学院两专业，不是 HKU 全校第二专业清单。硕士项目为经官方目录核实的**代表性可选例子**，没有穷尽全世界项目。本科到硕博或职业的连接属于课程匹配分析，不等于保证录取、免先修或就业。第二专业和 minor 的建议需再核对学分、先修、选课名额及资格，QFin 第二专业有甄选。

薪酬口径：Morgan McKinley 2026 职位 Low / Median / High；Randstad 2025 精算 Associate 基础月薪；美国 BLS May 2025 全国全经验职业中位数。研究职位与不对应的海外职业保持空白。没有把职位市场数字当作毕业生起薪、学历溢价、分位数或第 N 年工资。将来本科毕业时的就业市场、硕士学费和奖学金费率需重新核查。

成本模型从本科毕业起比较两个恒定实际工资情景：直接就业 vs 全日制升学后就业。总学费在起点支付；学习期记录资助和相对就业新增生活开支；支持不足一整年和资助提前结束。折现采用月度现金流及年折现率换算。默认工资是可调示例，不是模型估计；不包含税、晋升、奖金、失业、通胀或投资回报。MSc AI、PGS、HKPFS 模板只提供标注年度的费用／资助参考；未来金额未定。不同来源资助不叠加。
