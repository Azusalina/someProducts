LOCAL SYNC

Bring your day home.

Connect your iPhone to the same Wi-Fi network as this PC. Complete these steps once.

01

Trust this PC

Scan with your iPhone camera, open in Safari and tap Allow to download the certificate profile. Install within 8 minutes, or iOS deletes the pending download.

Immediately open Settings → Profile Downloaded → Track Local Sync → Install. If Profile Downloaded is missing, download the profile again.

Then: Settings → General → About → Certificate Trust Settings → enable full trust for Track Local CA.

Certificate fingerprint (SHA-256)

This profile contains only a certificate. It does not install a VPN or device management.

02

Configure Overland

Scan this second code to open Overland and set the receiver, access token and device ID.

Manual configuration

Device ID: iPhone. Give each phone a different ID if you add more.

03

Keep the whole trace

  • Logging Mode → All Data; Locations per Batch → 200.
  • Tracking Enabled → On; Location Authorization → Always; Precise Location → On.
  • For detailed traces: Continuous Tracking → Standard; Desired Accuracy → 10 m. Start here and check daily battery use.
  • For the initial continuity test: Pause Updates Automatically → Off. This uses more battery; tune it after a real walk.
  • Send Interval → 5 minutes; leave “Consider HTTP 2XX Successful” off.

Tap Send Now in Overland. When this PC confirms the batch, it is safely archived here and removed from the phone's pending queue.

If the first sync does not arrive

Check the Wi-Fi network, certificate trust, receiver address and access token. Allow the HTTPS upload port through your PC firewall. Guest Wi-Fi or VPN LAN blocking can prevent access; do not turn off a VPN automatically. DHCP reservations keep the PC address stable.
