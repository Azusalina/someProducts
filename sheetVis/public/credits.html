开源项目与音色来源

识别、解析、乐谱排版与钢琴音色使用以下项目。运行时音色与前端库均从本机加载；这里的外部链接仅供查看来源。

Audiveris

本地 PDF 乐谱识别。版本 5.11.0，GNU AGPL v3。以独立命令行进程运行，原安装包和运行时保存在产品目录。

GitHub / 源代码 · 随包许可证 · 使用版本的完整源码

OpenSheetMusicDisplay

MusicXML 五线谱排版。BSD-3-Clause，Copyright 2019 PhonicScore。实际依赖版本以 package-lock.json 为准。

GitHub · 许可证

Tone.js MIDI

MIDI 文件解析。MIT，Copyright 2016 Yotam Mann。仅使用 MIDI 解析包；播放调度由 sheetVis 的 Web Audio 播放器实现。

GitHub · 许可证

fflate

解压 .mxl 格式的 MusicXML。MIT，Arjun Barrett。

GitHub · 许可证

本地钢琴采样

采样来自 Nicholaus P. Brosowsky 的 tonejs-instruments 项目，原钢琴来源标为 VSO2 / Versilian Studios。项目将编辑后的采样以 CC BY 3.0 发布。sheetVis 选取 29 个 MP3 文件，原文件未修改；播放时对邻近采样进行实时变调及音量包络处理。

GitHub · 项目许可说明 · 原始来源表 · CC BY 3.0 · 使用的提交与文件校验值

Tesseract 英文 OCR 模型

使用包含 legacy 数据的 tessdata 英文模型，供 Audiveris 识别速度及英文标题等文字。Apache-2.0。

GitHub · 许可证

示例乐谱

“小练习 · C 大调”为 sheetVis 首版编写的简单示例，没有复制第三方曲谱。

具体依赖版本见 package-lock.json；下载来源与 SHA256 见 .runtime/provenance.json 和 samples/manifest.json。外部运行时及依赖保留其各自许可证。
