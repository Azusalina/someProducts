# sheetVis

## What is it?

本机运行的钢琴乐谱瀑布播放器。导入清晰 PDF 后，本地识别并播放；也可直接导入 MusicXML 或 MIDI。五线谱、音符瀑布与钢琴声音共用播放时间线，支持调速、暂停、快进和回退。

识别结果可能包含错音或节奏偏差。详细功能、开源来源、限制与验证记录见 [description.md](description.md)。

## How to use

适用环境：Linux x86_64，现代 Chromium／Firefox 浏览器，Node.js 20.19+（或 22.12+）、npm、Python 3.12+，以及 `ar`。Audiveris 自带 Java 运行时，无需另外安装 Java。

可选的 Poppler 工具 `pdffonts`、`pdftotext` 用于读取数字 PDF 内嵌拍号，当前 Linux 电脑已具备。缺少时仍可使用 Audiveris 图像识别。

首次准备需要联网下载依赖、本地识别引擎和钢琴采样；准备完成后运行无需联网：

```bash
cd /home/a/Documents/someProducts/sheetVis
npm ci
npm run setup
npm run build
./launch.sh
```

`launch.sh` 会打开浏览器。也可运行 `npm start`，然后访问 <http://127.0.0.1:4280>。关闭启动终端或按 `Ctrl+C` 停止服务。

默认读入 `config.json` 中指定的 `/home/a/Documents/materials/PianoSheets/chopin_ballade1.pdf`。已完成的相同 PDF 复用本地识别记录，刷新不会重复识别。浏览器首次打开需要点击“播放”或按空格启用音频；之后导入文件可自动播放。默认文件缺失会显示错误；工具栏仍可导入其他文件或选择示例。

- 默认深色界面，工具栏收起。点击右侧“工具”或按 `Tab` 呼出右侧垂直工具栏，`Esc` 或关闭按钮收起。
- 从工具栏“导入”或将文件拖入瀑布区。支持 `.pdf`、`.musicxml`、`.xml`、`.mxl`、`.mid`、`.midi`，文件最大 40 MB。
- PDF 先筛选含五线谱的页面，作曲家介绍、作品说明等无谱页不参与音符识别。页面显示筛选／识别百分比进度，完成后默认自动播放；取消“自动播放”可改为手动开始。多乐章结果可以切换乐章。
- 文件读入后显示文件名、大小、页数与状态。点击“反馈”展开音符／分手统计、引擎节奏异常、起奏位置缺失和播放限制。检查结果不提供未经原谱核对的准确率。
- 工具栏“瀑布配色”可调整左右手、触键和背景颜色，立即生效并保存到当前浏览器。`config.json` 的 `colors` 是默认配色；“恢复配置配色”清除浏览器覆盖。修改配置文件后刷新页面即可读取。
- 工具栏“Zen”或非输入区域按 `Z` 进入只显示瀑布与键盘的模式，`Esc` 退出；空格、方向键、点按琴键与高度拖动继续可用。
- 上下拖动钢琴上边界可调整琴键高度，设置保存在浏览器中。点按白键或黑键发出对应音高，不改变当前播放位置。
- 左侧显示上传的原 PDF，右侧显示瀑布与键盘。播放时高亮当前音符及和弦，并自动切换页面；“跟随”可关闭自动换页，页码和箭头可手动浏览。未找到可靠原谱坐标的音符不显示猜测光标。定位覆盖率不等于识别准确率。
- 底部常显“播放／暂停”和可拖拽的进度条。拖动期间暂停，松开后恢复之前的播放状态；暂停时也可拖动定位。“工具”中的 `−5s`、`+5s` 和小节按钮也控制位置。空格切换播放／暂停，播放按钮或进度条聚焦时同样有效；文字、数值和选择输入保留自身键盘操作。左右方向键跳转，`Home` 回到开头。
- 识别结果支持八度线、行内高／低音谱号变化、延音线、连奏线和三／五连音。延音线合并时值，连奏线保留各音并衔接；“反馈”显示识别标记数量及缺失配对。八度线终点等漏识别仍需核对原 PDF。
- 速度范围为 0.25–2 倍，保持音高。BPM 可输入 20–300，用于校正未识别的参考速度；倍速基于该参考速度。可独立关闭左右手声音、调整音量和瀑布预览时长。
- PDF 默认显示原文件；从工具栏“五线谱”按需打开重建预览，避免载入长谱时等待整首重新排版。可下载识别后的 MusicXML，在其他乐谱软件中修正。MIDI 不提供五线谱预览。
- 默认服务仅监听本机。用 `python server.py --port 4282` 更改端口；设置 `SHEETVIS_AUDIVERIS=/绝对路径/Audiveris` 可使用已有引擎。`config.json` 的 `default_score` 可设为空以默认打开示例，也可用 `SHEETVIS_DEFAULT_SCORE=/路径/乐谱.pdf` 覆盖。`recognition_timeout_seconds` 设置识别预算（默认 3600 秒，范围 30–7200）；失败任务保存 `.omr` 阶段，重新导入相同 PDF 可继续。

识别记录与原 PDF 保存在 `.data/`，依赖引擎保存在 `.runtime/`，钢琴采样保存在 `public/samples/`。停止服务后可删除 `.data/` 清除识别记录。无需系统安装；停止服务并删除产品文件夹即可移除工具。
