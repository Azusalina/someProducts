## What is it?

graphVis 是极简的离线函数绘图与微积分可视化工具。输入表达式即可绘图，支持参数滑块、导数曲线、可拖动切线、定积分阴影和累积积分曲线。

设计参考 Desmos / GeoGebra 的公开交互，MathLive 编辑器与字体随项目保存，运行时无需网络。架构、来源、算法、限制与验证记录见 [description.md](description.md)。

## How to use

在线打开 [graphVis](https://azusalina.github.io/someProducts/Visualize-graph/)，或离线使用下述方式。

使用支持 Canvas、ResizeObserver、Web Components 和 FontFace 的现代浏览器，直接打开本文件夹中的 [index.html](index.html)。无需安装、编译或联网；保留同目录的 CSS、JS 和 vendor 文件夹。

每次打开或刷新均为空白，全部设置重置；x/y 单位比例为 1:1，屏幕中心为 (0,0)。F5、Ctrl+R / Cmd+R 先弹出确认框，Enter 确认刷新，取消则保留当前内容。浏览器刷新按钮和关闭页面时使用浏览器原生离开提示（是否显示及按键由浏览器控制）。点击左上角唯一的 `⋮` 按钮，呼出表达式列和工具栏；再点收起。表达式列只放公式、计算结果和定义变量时附加的滑块，其他控件在独立工具区。

符号命令须显式以反斜杠输入，例如 `\in`、`\pi`、`\alpha`；普通 `in` 不自动变为 ∈；`int`、`sum` 是例外，会直接展开为带上下限的积分 / 求和符号。转义输入中按 Enter 先解析当前命令（如 `\int^1_0`），完成后再按 Enter 才新增行。支持直接键入或粘贴数学 LaTeX，编辑和数学结果都显示为排版后的公式。例如：

```text
f(x)=\sin x
f'(x)
\int_0^x f(t)\,dt
```

- 普通单击输入框将光标移到末尾；拖选、Shift 选择及双击选中保留。浅色模式使用浅蓝选区背景。
- `Enter` 新建下一行；方向键在行首、行尾切换；空行按 Backspace 删除。支持多行粘贴和数学编辑器的括号、分数、上下标编辑。
- `a=(1,2)` 定义命名点，坐标也可用已定义参数，例如 `t=2` 后写 `a=(t,t^2)`。点旁显示名称和坐标；选中公式后，用工具栏颜色选择器自选点颜色，JSON 会保留颜色。坐标须为有限实数或参数表达式。
- `a=2` 在公式下方附加参数滑块；范围与步长在工具区的“参数”中设置。`sinx`、`sin x` 等价于 `sin(x)`；`sin^n(x)` 表示 `(sin(x))^n`，n 可由参数定义。
- 工具栏的 f(x) 按钮展开独立数学工具区，在“微积分”选择函数，勾选切线或定积分；修改 x₀、a、b，或直接拖动图上的切点和边界。“面积颜色”可自选填色；交换上下限时积分数值符号反转。
- 复数可输入 `2+3i`、`i^2`、`sqrt(-1)`、`exp(i*pi)`，或定义 `z=1+2i` 再计算 `z^2`。`re(z)` / `im(z)`、`conj(z)`、`abs(z)` / `arg(z)` 分别求实部/虚部、共轭、模/幅角。复数常量绘为 (实部,虚部) 点，`f(x)=x+i` 的实部曲线为实线，虚部为虚线。
- 定义域可直接写 `sinx{0<=x<=2pi}` 或 `f(x)=sinx{0<=x<=2pi}`，只在指定范围绘图；`<=` 包含端点，`<` 排除端点。
- `d/dx(x^2)`、`d/dx f(x)`、`\frac{d}{dx}f(x)` 都可输入并绘制导数。
- `lambda=4` 后输入 `x~poisson(lambda)` 绘制 Poisson 概率质量函数。也支持 `binomial(n,p)`、`n(mu,sd^2)` / `normal(mu,sd^2)`（第二个参数为方差）、`uniform(a,b)`、`exponential(rate)`；`pdf(normal(0,1),x)`、`pmf(poisson(4),x)`、`cdf(poisson(4),x)` 分别绘制密度、概率质量和累积概率。`p=poisson(4)` 后可用 `p.pdf(x)` / `p.cdf(x)`。
- `X~poisson(4)` 后输入 `P(X=2)` 或 `p(X=2)` 计算单点概率；先定义 `n=3` 也可输入 `P(X=n)`，随滑块更新。连续分布单点概率为 0，密度值请用 PDF。
- 离散分布显示整数点与竖线，区间操作显示包含端点的概率和，累积按钮生成 CDF 阶梯图。普通整数函数可写 `discrete(x^2)`。图区悬停显示十字光标、坐标和函数值；离散函数吸附最近整数。
- 编辑积分公式时，↑ 进入上限、↓ 进入下限；数值工具区也可用 ↑ / ↓ 在 a、b 输入框间切换。`\int_0^2 x^2dx`、`int f(x)dx` 不需要在被积式外加括号，支持 `dx`、`d x`、`\mathrm{dx}`。
- 输入积分表达式后自动绘制被积函数并填充积分面积；累积积分曲线用虚线显示。定积分按公式中的上下限填色，含 x 的上限使用工具区 b 的当前值预览。
- `\sum_{n=k}^{p} n^2` 可按 ↑ / ↓ 切换上、下限；先定义 `k=1`、`p=3` 即可用滑块调整。也支持 `sum(n^2,n,k,p)`、`sum(n=k,p,n^2)`；`sum(n=k,p)` 默认累加 n。求和上下限均包含，要求有限整数。
- Ctrl+点击两个表达式可标记当前视窗内数值检测到的全部交点及坐标，再选同一对可取消；支持切点，随表达式或视图更新。重合曲线不是有限个交点；高频振荡或退化关系的数值搜索可能遗漏。
- 按住 Ctrl 依次点击两个已定义的点，创建经过两点的完整直线及方程，默认名称为花体 ℓ 加右下标 1、2……；竖直线使用 x=常数。任意曲线位置、交点标记不能作为选点。Esc 取消选点；方程使用创建时的坐标，之后可编辑、隐藏、改色、删除、撤销及随 JSON 保存。
- `int(f(x),0,2)` 求定积分数值；`int(f(x),0,x)` 绘制累积积分；`int f(x) dx` 选择 F(0)=0 的原函数。使用其他起点时显式填写下限。
- “1:1”按钮回到中心 `(0,0)` 和初始等比例视图，不清空公式；`x＋ / x−`、`y＋ / y−` 分别放大 / 缩小对应轴，另一轴及视图中心保持不变。
- 拖动图区平移，滚轮或 `＋ / −` 缩放；“⌂”恢复视图，“适应”按当前横轴范围调整函数视图。一般函数默认等比例；概率图自动分别缩放两轴，方便看清密度或概率值。
- “视图”设置网格、弧度/度、中心、两轴范围和等比例坐标。工具栏的月亮按钮切换深色模式。小键盘按钮单独位于屏幕底部，按需显示或隐藏小键盘。Ctrl+/ 呼出工具，Esc 收起。
- 选中公式后，用工具栏的可见性、颜色、删除按钮操作当前表达式。“保存 / 打开”导出、导入 JSON 项目；“PNG”导出图区。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。

页面不自动保存或恢复项目；刷新会清空内容，重要项目请先“保存”下载 JSON，再用“打开”恢复。“打开”会替换当前项目，可撤销。浏览器若限制本地文件，可在该文件夹运行 `python3 -m http.server 4178 --bind 127.0.0.1`，再打开 `http://127.0.0.1:4178/`；用 Ctrl+C 关闭服务。

没有系统安装或后台服务。移除时删除本文件夹；浏览器中的记录可在网站存储设置中清除。
