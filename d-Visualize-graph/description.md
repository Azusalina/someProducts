# graphVis

## 范围与设计

2026-10-14 的第一版面向快速实用的二维表达式绘图与微积分可视化。用户明确选择离线本地网页，并以 Desmos 的表达式、f′(x) 和 ∫f(x)dx 交互为主要参照。

当前工具栏按需呼出，提供表达式操作、撤销/重做、项目文件、图像导出和独立数学工具区；表达式列只包含公式、计算结果与真实错误。没有装饰性图片、账户、遥测或外部请求；数学字体保存在本地，数学编辑器关闭声音与自动弹出的小键盘。曲线颜色用于区分数学对象；面积颜色表示积分符号。小屏幕将面板作为可收起的覆盖层，保留绘图区。

## 功能与输入

支持实数的四则运算、右结合幂、隐式乘法 `2x`、`a(x+1)`、常量 π/pi、e、tau；一元函数定义及组合、数值常量及依赖、前向定义引用、滑块、垂直直线、点、隐式方程和不等式。支持 `sinx`、`sin x` 等省略括号的一元函数写法，以及 `sin^n(x)` / `\sin^{n}(x)` 的函数值幂，`xy` 是一个变量名，乘法应输入 `x*y`。基础函数库保持与 1.0 相同，界面已移除输入帮助与示例。

函数可写作 `f(t)=t^2`；定义域限制如 `f(x)=sqrt(x){x>0}` 或 `sin(x){-2<x<2}`。首版只支持一元自定义函数。重复定义、循环依赖、未定义符号和错误参数在对应行显示，不影响其他有效图形。

`f'(x)` 与 `diff(f(x))` 绘制一阶导数，`f''(x)` 绘制二阶导数；`f'(2)` 和 `diff(f(x),2)` 显示指定位置的斜率。切线使用

```text
y = f(x₀) + f′(x₀)(x − x₀)
```

切点横坐标支持数字、滑块和图区拖动；悬停显示坐标及所选函数值、导数值。

`int(expr,a,b)` / `integral(expr,a,b)` 求有限区间定积分；`int(f,a,b)` 允许将已定义函数作为积分对象。`int(expr)` 与 `int expr dx` 定义 `F(x)=∫₀ˣ expr(t)dt`，因此 F(0)=0，仅选择一个原函数，不表示全部原函数 F+C。可显式选择其他起点。被积式中的 x 作为积分的局部变量，暂不支持另外独立于积分变量的外部 x 参数。

定积分阴影的符号按上下限方向计算：a<b 时上方为正、下方为负；a>b 时反转。下限、上限支持拖动，无需来回切换编辑框。图区导出只包含网格、数学对象与可视化标记，不含控制面板。

1.0 的运行代码为五个文件，约 64 KB。1.1 在此基础上增加 LaTeX 转换、数学编辑器适配与本地 MathLive/字体；无需构建。解析一次生成可重复求值的闭包；没有 eval 或 Function 代码生成。编辑立即重新解析，绘图由 requestAnimationFrame 合并；同一视图内缓存采样。悬停只重画独立覆盖层。常规曲线约每 2 CSS 像素采样，按中点偏差细分，间断点断开。含数值积分的曲线采用更稀疏的起始采样来控制开销。

隐式关系按约 7 CSS 像素的网格采样，拖动时为 12 像素；使用约 6 ms 的分帧工作片段，并取消旧视图绘制。这限制每个片段的阻塞时间，不保证全部关系在单帧内完成。像素级小对象、极窄区域和高频振荡可能遗漏。表达式长度最多 600，项目最多 64 行，嵌套深度 48，定义依赖最多 32 层。积分迭代有固定上限，嵌套积分不支持。

## 算法、假设与限制

一阶导数在表达式树上应用链式、乘积、商与幂规则，并将角度单位纳入三角函数导数。二阶 prime 及部分嵌套微分采用五点中心差分，步长约 `1e-4 max(1,|x|)`。实数绘图核中的非实数、无穷值与已识别的不可微点显示未定义；1.4 起显式复数表达式走独立复数层。限制区间的边界采用保守的邻域检查。复合表达式可去除的尖点可能仍显示未定义，首版没有 CAS 化简或符号求解结果输出；表达式与数值结果采用 LaTeX 数学排版。

积分采用自适应 Simpson 法，绝对误差目标 1e-7、八个初始面板、递归深度 13，最多约 8192 次求值。非有限采样或未满足收敛条件返回 NaN。该误差估计不构成对任意函数的保证；高频振荡可能发生采样混叠，孤立奇点可能未被命中。只支持有限区间的常规数值积分，包含无穷端点、反常端点、极窄峰或严重奇点的积分不在承诺范围。导数和图像也不能替代精确的数学证明。

一般函数默认采用等比例 x/y 单位，避免圆被显示为椭圆；1.2 起允许独立纵轴范围，概率图默认独立缩放。“适应”针对当前横轴范围采样，并截去两端各约 3% 的极端 y 值以减少渐近线影响；不是全局定义域分析或全局极值求解。严格不等式边界用虚线，但网格着色为近似。

无 3D、动态几何构造、矩阵、统计推断、参数曲线、任意 LaTeX 文档命令、`.ggb` 导入或 Desmos JSON 兼容。现代浏览器直接文件模式可离线运行；file:// 本地存储行为因浏览器而异，JSON 是便携备份。

## 1.1：LaTeX 与纯表达式列（2026-10-14）

首次打开不预填示例或绘图，工具栏默认关闭。三点按钮同时呼出工具栏与表达式列，旧的三横按钮已删除。表达式列仅包含数学编辑器、计算结果和对应错误；不放标题、添加按钮、颜色按钮、删除按钮、帮助、参数滑块或微积分面板。当前表达式的添加/删除/颜色/可见性在工具栏，微积分、参数和视图设置在独立工具区。小键盘按钮独立放在屏幕底部，编辑器自身的菜单与小键盘切换按钮隐藏；小键盘只由底部按钮触发。

`latex.js` 将受支持的数学 LaTeX 转为原有表达式树，并将表达式树转回数学排版。覆盖分数、根号/指定次根、上下标、常用希腊参数、三角函数、prime 导数、d/dx、有限上下限积分与定义域。`sinx` 表示 sin(x)，`sin x^2` 表示 sin(x²)，`sin^n(x)` 表示 sin(x) 的 n 次幂；负指数仍是函数值的负次幂，不是反函数。复合参数建议显式加括号。绘图核与原有一阶导数/数值积分方法保持不变，不引入 CAS。

公式字段、源函数选择、数值结果、切线/积分读数、悬停读数和图上数学标记以 MathLive 数学排版显示。坐标轴数字使用数学字体；数字编辑控件仍保留可直接修改的数值。界面没有输入指南、示例列表、自动提示、默认示例或常驻性能信息。文档继续保留必要的操作说明。

使用 [MathLive 0.111.1](https://www.npmjs.com/package/mathlive/v/0.111.1)（[源码](https://github.com/arnog/mathlive)、[API](https://mathlive.io/mathfield/api/)），版本固定、MIT 许可证随包保留，来源/散列见 `vendor/mathlive/PROVENANCE.md`。仅复制浏览器包、静态 CSS 与 woff2 字体；不包含声音或 Compute Engine。编辑器配置将字体指向当前文件夹的绝对本地 URL，禁用声音、Compute Engine、菜单与输入建议弹窗。页面不依赖 CDN。

浏览器存储使用 `graphVis.v2`，避免旧版自动预填的示例再次出现。旧键 `graphVis.v1` 保留，未删除；旧版 JSON 项目仍可以打开。当前真正编辑过的项目仍会自动保存，重新打开时工具栏保持关闭。

新增 `editor.js`、`latex.js`、MathLive vendor 与 `tests/latex.test.cjs`；DOM 集成测试改为加载真实 MathLive 组件与静态排版器，字体、滚动、Canvas 和虚拟键盘可见性依赖由测试环境提供替身。此验证覆盖字段值与事件，不等于真实浏览器、键盘布局、触屏或 file:// 字体加载测试。当前仍无浏览器连接。

## 1.2：概率、变量滑块与深色模式（2026-10-14）

变量定义现在在公式下追加滑块，范围与步长设置仍留在独立工具区；此行为取代 1.1 的外置滑块。独立常数表达式（如 a=pi/2）也可生成滑块，依赖其他变量的定义不重复生成滑块。分布定义本身不生成数值滑块。分布参数提供合法范围提示：Poisson λ≥0，Binomial n 为非负整数、p∈[0,1]，Normal σ>0，Exponential rate>0。

支持普通 d/dx、LaTeX 分数微分符号和 prime；d/dx 后括号包含完整待微分式，未加括号时作用于下一个函数或幂原子。概率表达式支持 x~poisson(lambda)、直接分布、pdf/pmf/cdf(distribution,x)，以及 p=poisson(4) 后 p.pdf(x)、p.cdf(x)。~ 表示可视化分布，不进行随机采样或数据拟合；输入时转换为数学符号 \sim。

Poisson 与 Binomial 绘为整数点和竖线，CDF 为右连续阶梯；normal、uniform、exponential 绘为连续密度。离散函数的区间操作使用包含端点的整数求和；概率分布使用 CDF 差计算区间概率。非整数边界采用 ceil(a)…floor(b)，a>b 返回 0。连续密度保留有符号数值积分；CDF 阶梯的积分按整数分段计算。离散函数禁用导数和切线工具，并拒绝将 PMF 当连续函数积分；任意整数函数可用 discrete(expression) 显式标记。

新概率图自动按分布主要范围和峰值分别缩放 x/y；参数变化时继续跟随，手动平移、缩放或设置范围后停止自动跟随。“适应”或“⌂”可重新适配分布；“等比例坐标”可恢复相同单位比例。已保存、导入和撤销恢复的视图不会被自动覆盖。两轴范围、主题均随项目保存，旧 JSON 没有 theme 时采用浅色。

编辑器使用高对比插入光标，呼出工具时聚焦公式；图上独立覆盖层显示十字光标、坐标和函数值，离散值吸附最近整数。深色开关调整面板、数学字段、键盘、网格、曲线和读数，不添加装饰。

统计核为独立实现，没有复制 SciPy 代码或新增运行依赖。定义参考 [Poisson](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.poisson.html)、[Binomial](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binom.html)、[Normal](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.Normal.html)、[Uniform](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.uniform.html)、[Exponential](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.expon.html) 的公开文档；MathLive 光标与键盘配置参考其 [API](https://mathlive.io/mathfield/api/)。

数值限制：Poisson λ 与 Binomial n 最大 10⁶。PMF 用 log-factorial 和 Stirling 展开避免阶乘溢出；CDF 用尾概率递推并限制迭代次数。Normal CDF 使用 erf 近似，常规范围误差约 10⁻⁷。极端尾区间的 CDF 相减会损失相对精度。普通整数求和、阶梯积分最多约 20,000 项；图上整数点/阶梯最多约 4,096 项，过宽视图采用整数步长抽样。Binomial 自动视图优先显示均值附近约六个标准差，完整支持集仍为 0…n。密度参数应为常量或定义变量；离散 PMF 的横坐标须直接使用函数参数，变换横坐标的离散支持集没有自动推导。此版本不提供统计检验、拟合、随机数、表格数据导入或通用离散集合。

## 1.3：方差记法、积分编辑与面积颜色（2026-10-14）

n(mu,sd^2) 与 normal(mu,sd^2) 均使用均值和方差。统计核将第二个参数开平方取得标准差，PDF、CDF、区间概率和自动视图共用此结果；normaldist 别名同样使用方差。这取代 1.2 的 normal(mu,sigma) 第二参数标准差约定，旧项目中非 1 的第二参数将按新约定解释。n 仍可作为数值变量（例如 Binomial 的 n 或 sin^n(x)）；n(...) 表示 Normal 构造。P(X=n) 与 p(X=n) 都可计算事件概率，仅比较参数触发概率语义，p=0.3、p(x) 等已有变量/函数用法保留。

积分扫描现在以顶层 differential 结束积分体，不要求被积式末尾括号提供词边界；支持 x^2dx、f(x)dx、d x、\mathrm{dx} 和已支持的 dt 换元，不把函数括号内的 dx 当外部终止符。积分后面仍能接 +1 等表达式。普通 int f(x)dx 输入走同一 LaTeX 扫描路径；int(f(x),a,b) 的函数式 API 保留。

数学编辑器上下键用公共 offset / getElementInfo 接口识别积分上下限分支，↑ 到上限末尾、↓ 到下限末尾，可继续键入；Shift 方向选择保留原行为，普通公式仍保留原来的跨行操作。独立数字输入区 a 的 ↑ 切换到 b，b 的 ↓ 切换到 a 并选中值。

顶层积分表达式的编译结果保留被积函数和上下限；直接计算定积分即使结果为标量，也自动绘出被积函数并按公式上下限填色。含 x 的上下限按当前 b 求值预览，未显式给界的 int(f(x)) 使用工具区 a、b；LaTeX 未给界时仍采用 F(0)=0。累积积分函数保留为虚线，被积函数用实线。“面积颜色”是独立工具区的颜色选择器，统一控制手动积分、表达式积分和离散区间填色；颜色随项目、自动保存和历史记录保留，旧项目缺少字段时默认蓝色。填色不改变积分符号或概率计算。

默认数值误差与离散函数积分限制沿用原约定。自动被积函数/面积展示目前针对顶层 int(...)、\int 或直接含积分的函数定义；int(...)+1 等组合仍能计算，但不会独立提取其中每个积分绘制额外面积。没有自动求取无限上下限或反常积分。
