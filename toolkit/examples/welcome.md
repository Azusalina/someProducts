# A page in the making

A local workspace for turning **plain text** into something you can read, refine, and share.

> Edit this file in your usual editor and save it. Your browser preview follows along.

## The small, useful things

- Clear headings and readable typography
- **Bold**, *italic*, and `inline code`
- Tables, quotes, links, and syntax-highlighted code
- Local images from this document's folder
- A finished PDF, only when you click **Export PDF**

## A simple workflow

| Step | What to do |
| --- | --- |
| Open | Enter the path to your Markdown file |
| Edit | Make changes in your favorite editor |
| Save | See the preview update automatically |
| Export | Download an A4 or Letter PDF |
