# Yupi Economics

## What is it?

An interactive HKDSE Economics study website with 20 chapters, diagrams,
practice questions, worked answers, and links to source scans. See
[description.md](description.md) for layout, sources, and deployment details.

## How to use

Open [the website](https://azusalina.github.io/someProducts/yupi-econ/) in a
modern browser, or open `claude-product/study-site/index.html` locally. Choose a
chapter and use its learning, practice, and review tabs. Progress, theme, and
language preferences stay in this browser's local storage.

No installation or configuration is required. For all controls, see
[claude-product/README.md](claude-product/README.md). The original `yupi/`
reference folder remains local and is excluded from Git and deployment.
