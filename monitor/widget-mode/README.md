# Monitor widget mode

## What is it?

The KDE Plasma 6 desktop mode of [Monitor](../README.md), with a transparent
modular widget and local telemetry bridge. See [description.md](description.md)
for the source layout and detailed documentation.

## How to use

Follow [core/README.md](core/README.md) for setup, preview, installation, module
controls, configuration, and note export. Run its commands from
`monitor/widget-mode/core`. [docs/README.md](docs/README.md) covers prerequisites,
service checks, persistent configuration profiles, and removal.
