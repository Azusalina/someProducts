    How to study with these pages

    1. Read the plain-words explanation first, then try the interactive box under it.
    2. Use the tables to memorise. The tables are the exam facts; the explanations are why they are true.
    3. Close each chapter with the "Check yourself" questions. Open the answer only after you have said yours out loud.

    Mistakes found in the notes

    While rebuilding the notes I found a few places where the PDF is wrong or unclear. Each one is also flagged inside its chapter, in an orange box. Confirm with your teacher or textbook if an exam answer depends on it.

    WhereNotes sayBetter version
    Ch17 portsFTP: Port 20FTP uses port 20 for data and port 21 for control commands.
    Ch17 PDU listData link layer: "Packet"The data link layer unit is a frame. The notes' own table on the same page says Frames.
    Ch17 OSI tableApplication = 1 ... Physical = 7Official numbering is the reverse: Physical = 1, Application = 7. Layer names matter more than numbers.
    Ch17 ports"1/number is proportional to security level"No such rule. Security comes from encryption (SSH is safe, Telnet is not), not from the port number.
    Ch17 DNSDomain Name ServerDNS stands for Domain Name System. The machines that answer are DNS servers.
    Ch18 footnote"ETF"Electronic Funds Transfer is abbreviated EFT.
    Ch20 paths.../ "for folder from the foot"The symbol is ../ (two dots) and means "go up one folder".
