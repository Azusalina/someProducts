Elementary web authoring

Plan, build, publish and test a website, from folder paths to site structure.

What web authoring is

Web authoring is creating a website: a collection of related web pages that are organised and linked together. There are two big design jobs:

Structure (the inside)

How the pages are organised and linked: which page leads to which.

Layout (the outside)

How each page looks: where text, pictures and menus sit.

  • Copyright: you need the owner's written permission before using their text, pictures, music or video.
  • JavaScript is a scripting language that adds behaviour (decisions, calculations) to a page. In the syllabus it is called a scripting language, not a programming language, because it normally runs together with another application, the browser.

Planning and organising a website

PhaseWhat you do
Planning
  • Identify the intended audience
  • Set clear objectives for the site
  • Design the information structure (inside)
  • Design the content and layout of each page (outside)
  • Prepare the materials: text, pictures, sound
Building
  • Use an IDE (integrated development environment) authoring tool
  • Use suitable multimedia
  • Group the content into categories
  • Avoid very long pages
  • Keep a uniform design
  • Add hyperlinks so visitors can navigate
  • Make pages load in a reasonable time
  • Keep content updated
Publishing and testing
  • Publish: upload all pages and the files they need to a web server
  • Test: find broken and missing hyperlinks, scan for outdated files, test the loading time of pages and the files they link to

Building with Adobe Dreamweaver CS3


Adobe Dreamweaver is a web authoring tool: you design pages and manage the whole site visually, and its tools automate page design and site maintenance. Building a site goes through four jobs:




JobWhat it means


DefiningGive the new site a name and choose its local root folder (the folder on your computer that holds the site).


ManagingCreate pages and build the site's structure. Manage files on your own computer and on the remote site. Track updates and broken links between files.


DesigningUse the tools, organised in bars and panels, to build the pages.


UploadingSend all the required files to the web server through the Files panel.





Check yourself


Name the two main design jobs in web authoring.
Structure (how pages are organised and linked) and layout (how each page looks).


List what you should test before and after publishing.
Broken and missing hyperlinks, outdated files, and the loading time of pages and the files they link to.


A page in pages/ links to images/logo.png in the site root. Write the relative path.
../images/logo.png: go up one folder out of pages, then into images.


Why might an absolute path stop working?
If the domain name or a folder name changes, the full address no longer points to the file.


Which structure fits a self-study course, and why?
Linear. Pages follow one clear order, so the learner always knows what comes next.


Which page is the parent of all pages in a hierarchical site?
The homepage, usually index.html.


Name the four jobs in building a site with Dreamweaver.
Defining, managing, designing, uploading.
