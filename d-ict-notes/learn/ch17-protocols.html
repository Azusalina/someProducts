Communication software and protocols

The rules computers follow to talk: layers, packets, IP addresses and domain names.

What a protocol is

A communication protocol is a set of rules about how data is formatted and signalled, so that every device on the path can understand it. Communication software (your browser, your mail program) uses a protocol to send digital messages through the network, working together with the communication devices.

The OSI model: seven layers

Sending a message is a big job, so it is split into seven smaller jobs. Each layer does one job and hands the result to the layer below. OSI means Open System Interconnection.

Watch a message get wrapped and unwrapped

On the way down, each layer adds its own label (a header) in front of the data, like putting a letter in an envelope, then that envelope in a bigger envelope. At the receiver, each layer removes its own label and passes the rest up.

    TCP/IP: how data crosses the Internet

    The Internet is a packet switching network: a big message is cut into small pieces called packets. Each packet travels on its own and may take a different route. TCP and IP split the work.

    IP addresses

    An IP address identifies a computer on a network, like a postal address. It has two parts: a network address (which network) and a host address (which device inside that network). Some addresses also start with a class number.

    IPv4 uses 32 bits, written as four groups of 8 bits (so there are (28)4 addresses in total). Example: 127.0.0.1 is 01111111.00000000.00000000.00000001 in binary, a class A address. Classes D and E are not used for normal computers.

    ClassStarts with (class bits)Bits that are networkBits that are hostNumber of hosts
    A0bits 1 to 7bits 8 to 31224 - 2
    B10bits 2 to 15bits 16 to 31216 - 2
    C110bits 3 to 23bits 24 to 3128 - 2

    Bits are counted from 0 on the left. The "- 2" removes two reserved addresses: all host bits 0 (the network itself) and all host bits 1 (broadcast to everyone).

    IP address explorer

    Type an IPv4 address, or pick an example. Orange = class bits, teal = network bits, grey = host bits.

    IPv6 was created because IPv4 addresses are running out. It uses 128 bits: eight groups of 16 bits, so (216)8 addresses. Example from the notes: 1010:0:0:8:800:2000:4:300.

    Domain names and DNS

    People remember names; computers need numbers. The DNS (Domain Name System) translates a domain name such as www.example.com into an IP address. A full name like that is called a fully qualified domain name (FQDN).

      Check yourself

      List the OSI layers from top to bottom.

      Application, Presentation, Session, Transport, Network, Data link, Physical.

      Which layer adds the IP address? Which adds the physical (MAC) address?

      The network layer adds the IP address (in the Network Header). The data link layer adds the physical address (in the Data Link Header).

      Name the data unit at the transport, network and data link layers.

      Segment, packet (datagram), frame.

      Why does TCP number every packet?

      Packets can take different routes and arrive in a different order. The numbers let the receiving TCP put them back in the right order and rebuild the file.

      What does IP do that TCP does not?

      IP adds the destination address, can fragment packets, and chooses the shortest path.

      Which class is 172.16.5.4, and how many hosts can its network hold?

      First byte 172 starts with bits 10, so class B. Hosts: 216 - 2 = 65,534.

      What does DNS do, and why is it needed?

      It translates a domain name into an IP address. People remember names, but routers and computers need the number.

      In http://www.google.com/google-earth/Readme.html, name each part.

      http = protocol; www = host name; google = second-level domain; com = top-level domain; google-earth = folder; Readme.html = document.
