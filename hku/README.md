## What is it?

以2027入學、HKU優先的JUPAS互動選科工作台。整理12個保留課程代碼的學額、教學、學生討論、就業與薪酬、升學及兩個方向的第二主修問題，並按你的預測成績提供資格提示和選科建議。

完整資料可直接閱讀 [Markdown dossier](data/dossier-2027.md)。來源、假設與驗證見 [description.md](description.md)。

## How to use

無需安裝或連網，使用較新的Chrome／Chromium、Firefox或Edge開啟 [index.html](index.html)，並保留整個資料夾。也可在本資料夾執行 `python3 -m http.server 8787 --bind 127.0.0.1`，再開啟 `http://127.0.0.1:8787/`。

- 在「探索課程」按代碼／關鍵字搜尋，點課名查看全部資料和原始來源。
- 展開「你的預測成績」調整等級及公民科狀態。公民科預設Attained，5*+預設按5*；各課程列出hku26.pdf的2026實際LQ／Median／UQ、公式及目前預測折算分，另查2027正式要求。
- 加入最多四項作並排比較，或加入「我的志願」排序、記筆記；JS6224保留歷史資料，2027請用JS6999。
- 志願和筆記存於當前瀏覽器；在「我的志願」匯出JSON備份。匯入會取代當前草稿。直接開檔與HTTP開啟可能使用不同儲存空間。
- 「選科指南」含個人建議及少量HKUST對照；「研究原文」可下載Markdown、課程JSON和來源索引。

不用安裝系統服務；關閉頁面即可停止。如用Python預覽，按Ctrl+C停止。移除時刪除這個資料夾即可；如需清除個人草稿，先匯出備份，再清除該頁的瀏覽器儲存資料。
