# Skill Manager 实现与维护

## 目标与界面

本地优先的技能、插件资源库，中文界面，不依赖远程 API、在线字体、CDN 或运行时外部素材。安装命令本身可按用户输入访问网络。

视觉参考 Apple 的通透材质、圆角、细边缘高光与层次关系，使用原生 CSS `backdrop-filter`、多层内阴影和边缘反光近似呈现；这是网页实现，不使用 Apple 的专有组件。默认玻璃填充不透明度 20%，文字透明度固定，范围 0–100%。支持深浅色、减少动画、减少透明度及不支持滤镜时的实色回退。桌面为来源、列表、阅读器三栏；窄屏改为列表与阅读器切换。

## 发现与状态

- 用户目录：`$CODEX_HOME/skills`、`$CLAUDE_CONFIG_DIR/skills`，默认分别为 `~/.codex` 与 `~/.claude`；另含 `~/.agents/skills`、`~/.agents/plugins`。
- 插件：Codex / Claude 的 `plugins/cache`，读取 `.codex-plugin/plugin.json`、`.claude-plugin/plugin.json` 及 portable `plugin.json`，遵循清单中的技能目录；Claude 注册记录中的额外安装路径也纳入扫描。
- 系统目录：`/etc/codex/skills`、`/etc/claude-code/skills`、`/usr/local/share/codex/skills`、`/usr/share/codex/skills`、`/usr/local/share/claude/skills`。
- 项目发现：从用户主目录递归查找 `.codex/skills`、`.claude/skills`、`.agents/skills`、对应插件目录、插件清单和独立 `SKILL.md`。不在常见安装路径中的源文件显示为本地目录，不据此推断 AI 已加载。
- 额外位置：界面可补充最多 20 个绝对路径或 `~/` 路径，适用于其他磁盘、非标准目录与超出默认深度的项目。Codex `skills.config` 中的显式路径也纳入扫描。
- 默认项目发现最多深度 12、50,000 个目录、25 秒。跳过隐藏目录（通过专门入口扫描的配置目录除外）、Git、依赖、构建产物、虚拟环境及暂存区；项目符号链接不递归，技能根目录内部解析符号链接。技能目录深度 7，插件缓存目录深度 6。
- 同一真实技能目录的多个入口合并为一项，保留每个入口、提供方、链接属性及实际位置。不同真实目录的同名技能保持独立。失效链接单独显示。
- Codex 状态取自 `config.toml` 中 `plugins` 配置；Claude 状态依据 `installed_plugins.json` 与用户 `settings.json` 的 `enabledPlugins`。配置或注册记录仍在而清单缺失的插件显示“文件缺失”，保留 CLI 管理入口。项目设置的启用覆盖、桌面应用的远程账户插件、当前会话加载结果不能由此完整推断。“仅缓存”表示未在所读注册记录中确认，不能等同于当前会话不可用。

界面展示实际检查目录、目录是否存在、耗时、扫描时间、权限错误及截断提示。无法保证发现无权限目录、其他用户主目录、未挂载磁盘或未补充的非标准隐藏目录中的资源；可添加明确位置后重新扫描。不会扫描会话、凭据或认证文件内容。

## 阅读与文档边界

YAML frontmatter 用于列表元数据；阅读模式去除开头的 frontmatter，原文完整保留。Markdown 使用 `markdown-it`，禁用内嵌 HTML；图片只显示替代文本，不自动请求外部资源。外部链接由用户主动打开，使用 `noopener noreferrer`；相对 Markdown 链接在阅读器中跳转。锚点暂不定位。

可打开当前资源内深度 4 的 Markdown 及插件核心清单（最多 200 项），单文件最大 2 MB。文件必须先出现在文档列表中，再校验真实路径仍在资源内部；目录与文件的越界符号链接不能用于读取任意文件。尚不提供 Markdown 编辑功能。

## 收藏、移除与恢复

`.data/state.json` 保存收藏、主题、不透明度、额外扫描位置及移除日志。设置写入按队列串行处理，临时文件原子替换。技能收藏 ID 使用真实路径摘要，多个入口共享收藏；插件 ID 同时区分提供方。移动或升级到新版本目录可能改变 ID，旧收藏不会自动匹配。

独立技能、未注册本地插件和失效链接通过 `rename` 移至原目录同级 `.skill-manager-trash/<uuid>`；链接移动只涉及链接本身。删除共享源目录前显示其他入口信息。恢复不覆盖已存在的文件，检查父目录及暂存目录真实位置。记录先写日志再移动，处理中断后根据暂存目标恢复记录。禁止对父目录为链接的入口执行移动，应从真实安装位置管理。暂存内容永久保留，空间回收由用户在系统终端处理。

插件内技能跳转所属插件；插件卸载通过 CLI 修改注册信息，避免直接删缓存造成失配。Claude 根据安装记录提供 user/project/local 范围和工作目录，使用 `--keep-data`；Codex 使用 `plugin remove`。缓存无注册记录时 CLI 可能拒绝卸载，错误如实显示。CLI 卸载不属于可恢复暂存，需要通过安装命令重新添加。未实际卸载本机现有插件以做验证。

## 网页终端与访问控制

显式点击运行后，以服务用户权限在指定目录执行 `/bin/bash -lc`。继承服务环境，支持多行命令、stdout/stderr 合并输出、标准输入逐行发送、退出码、停止进程组、15 分钟超时、结束后重扫。输出仅保留最后 1,000,000 字符；本次进程内最多保留最近 20 条命令记录，不写入磁盘。服务重启清空命令记录。使用管道而非 PTY；需要 TTY、全屏交互或复杂密码提示的安装器应在系统终端运行。

同一时间执行一个命令；文件操作与运行中的命令互斥。服务退出时停止运行中的进程组。脱离进程组的后台进程、命令自行守护化、以及并发外部安装器不在此控制范围内。用户自行输入的命令拥有正常账户权限，服务不构造额外的命令沙箱。

HTTP 固定绑定 `127.0.0.1`；校验 Host、Origin、Fetch Metadata，API 需要启动时随机生成的会话 token（通过同源 bootstrap 提供），不开放 CORS。拒绝跨站请求及 DNS 重绑定主机名，JSON 请求上限 64 KB。静态文件采用固定白名单，CSP 禁止外部脚本、框架嵌入及外部自动请求。其他同账户本地进程依然可以调用服务；它不是多用户鉴权网关。

## 文件与运行

- `src/scanner.mjs`：目录发现、配置/清单解析、资源合并、文档列表及读取。
- `src/state.mjs`：本地持久化与移除日志。
- `src/actions.mjs`：移除计划、暂存、恢复与插件命令生成。
- `src/jobs.mjs`：命令生命周期、输出、输入、终止。
- `src/server.mjs`：同源 HTTP 服务、API 与 Markdown 渲染。
- `public/`：纯 HTML/CSS/JS 界面，无构建步骤。
- `scripts/service.py`：systemd 用户服务安装、状态、移除；`install --print` 仅输出 unit。
- `tests/`：临时测试目录中的核心/API 与 Chromium 操作测试。
- `artifacts/`：忽略提交的截图、浏览器验证结果及临时验证产物。

systemd unit 写入 `~/.config/systemd/user/skill-manager.service`，使用当前 Node 绝对路径、绝对工作目录、安装时 PATH，启用登录启动及失败重启。既有 unit 必须含本产品标记才允许覆盖或删除。移除服务保留 `.data`、技能与插件。

## 多选与批量操作（2026-10-25）

列表复选框独立于正在阅读的文档，支持跨筛选保留选择、全选当前结果、部分选中的中间状态、Shift 连续选择及清空选择。选择仅保留于当前页面，刷新后重置。筛选隐藏的选择仍会参与批量操作，批量栏明确显示其数量。

批量收藏 / 取消收藏通过一次校验和一次原子设置更新完成；无效项目不会造成部分收藏。批量移除先生成逐项计划，列出共享技能的具体安装入口、别名影响、插件卸载命令与工作目录，支持切换 Claude 安装范围。每个已合并技能选择一个安装入口；移除符号链接仍保留源目录。捆绑技能只在所属插件被选中时随插件处理，否则标记跳过，并提供“一并选择所属插件”。相同工作目录和相同命令只运行一次，嵌套目录合并处理。

计划摘要在确认执行前重新扫描校验；安装信息发生变化时拒绝直接执行，要求重新核对。执行期间单项移除、恢复及新终端命令被拒绝，避免与批量任务交叉。任务按顺序执行，逐项记录成功、失败、跳过、停止及最近 100,000 字符的命令输出；独立目录仍走原有可恢复暂存流程。发生部分失败时保留已经成功的结果，不做跨项目回滚；成功项取消选择，未执行或失败项保留以便重试。停止会终止当前 CLI 进程组并跳过后续项目；正在进行的文件移动会先完成。

任务进度与结果保存在服务内存，可关闭确认窗口后从列表底部“批量进度”重新查看；刷新页面会恢复正在运行的任务轮询。服务重启不会恢复任务队列，已完成的暂存仍有磁盘日志可恢复。最多一次选择 500 项。`src/batch.mjs` 实现计划、去重、摘要校验、执行与停止；新增 `/api/batch/pin`、`/api/batch/plan`、`/api/batch/remove`、`/api/batch`、`/api/batch/cancel` 接口，沿用同源与 token 限制。

验证：13 项核心/API 测试和 27 项 Chromium 浏览器检查通过。新增测试覆盖共享入口、插件范围、捆绑技能、重复命令合并、计划失效拒绝、部分失败重试、停止进程组、后续项目跳过、收藏原子性、跨筛选多选、全选中间状态、批量移除后恢复、手机批量栏及无横向溢出。真实第三方插件批量卸载未执行；CLI 调度测试使用临时目录和命令替身，不改变用户安装。
